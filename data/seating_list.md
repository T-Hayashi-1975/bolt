# 席次リスト（写真OCR抽出）

写真から手動OCRで抽出した席次表データ。  
写真の解像度・角度の関係で判読困難な箇所が多く、**推測を含む暫定版**です。  
原本（紙）との突き合わせ確認が前提です。

## 信頼度マーカー

| 記号 | 意味 |
|---|---|
| ◎ | 明瞭に読み取れる |
| ○ | ほぼ確実（一般的な漢字・社名のため推定可） |
| △ | 要確認（複数解釈の可能性あり／一部判読不能） |
| ✗ | 判読不能（記号や枠は見えるが文字が読めない） |

判読不能の文字は `?` または `[判読不能]` と記載。  
「同」は「上の人物に同じ／同行者」の意。

## 検索方法

```bash
# テーブル A の全件
grep -E "^\| A " data/seating_list.md

# 氏名で検索
grep "鈴木" data/seating_list.md

# 番号で検索（テーブルA の 5 番）
grep -E "^\| A \| 5 " data/seating_list.md

# 組織名で検索
grep "三菱重工" data/seating_list.md
```

エディタで開いた場合は Ctrl+F / Cmd+F でフィルタ可能。

## 写真の構成

写真には大判の席次表が写っており、左から順に以下のセクションが見える：

- **L列**：写真左端、左半分が見切れている縦長セクション（番号は読み取り困難）
- **A列**：「A」ラベル付き縦長セクション（行 ①〜⑲）
- **B列**：A と C の間。写真ではほぼ見切れており本書では未収録
- **C列**：「C」ラベル付き縦長セクション（行 ①〜⑲）
- **R列**：写真右端、右半分が見切れている縦長セクション（番号読み取り困難）
- **4 / 5**：下部にラベル「4」「5」のセクション（上端のみ見える）

各セルには「番号」「区分（自衛官／国会議員／F／A会等）」「組織」「役職」「氏名 様」が含まれる。

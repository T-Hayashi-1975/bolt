# 名古屋市企業進出促進補助金 — 事前相談メモ／質問リスト

> [!info] このノートについて
> 名古屋市 経済局 イノベーション推進部 産業立地交流課への**事前相談**で使う想定。
> 関連メモ: [[名古屋市企業進出促進補助金 制度概要]]

> [!warning] 最重要
> **賃貸借契約を結ぶ前に**相談すること。申請期限は「**賃貸借契約の前日まで**」。契約後は申請できません。

---

## 0. 相談の目的（最初にこれを伝える）

> [!quote] 切り出し台本
> 「過去に、金融機関の融資を受ける目的だけのために、名古屋市内のマンションの一室に事務所登記をしたことがあります。
> 実態のある事業所を市内に新設して本補助金を申請したいのですが、この過去の登記があることで
> 『市内に初めて開設する事業所』に該当せず、対象外になってしまうかを確認したいです。」

## 2. 問題になっている「過去の事務所登記」の事実関係 ⭐最重要

> [!important] ポイント
> 役所はこの**実態**と**登記記録**で判断する。「登記のみ・実態ゼロ」であるほど、本来の意味の『事業所』ではないと説明しやすい。

- [ ] ① 登記した所在地（名古屋市内のマンションの住所）：
- [ ] ② 登記した時期（年月）：
- [ ] ③ 登記の種別（本店／支店／事務所 のどれか）：
- [ ] ④ 登記の目的：金融機関からの融資を受けるため（実態を伴う事業所ではない）
- [ ] ⑤ その場所での**事業の実態の有無**（なし／一部あり）：
- [ ] ⑥ その場所に**人員（常駐者）はいたか**（いない／いた 人数）：
- [ ] ⑦ その場所に**什器・設備・電話・看板等**はあったか（なし／あり）：
- [ ] ⑧ 賃貸借契約・利用料の支払いはあったか（なし／あり）：
- [ ] ⑨ その登記は**現在も残っているか**（現存／抹消済み／移転済み）：
- [ ] ⑩ 登記簿（履歴事項全部証明書）の履歴に**過去所在地として残っているか**：
- [ ] ⑪ 当時その所在地で**法人住民税の均等割等の申告・納付**をしていたか：

## 4. 役所に確認する質問リスト

### A. 今回の核心（過去登記の扱い）
- [ ] 1. 過去に「融資目的・実態なし」で市内に事務所登記していた場合、**「市内に初めて開設する事業所」**要件から外れるか？
- [ ] 2. 判断は**登記簿の記録（履歴）**で機械的に行うか、それとも**実態（人員・設備・業務の有無）**を踏まえるか？
- [ ] 3. 過去登記が**現存**する場合と**抹消済み**の場合とで結論は変わるか？
- [ ] 4. 「既に市内に事業所がある場合は対象外」の**「事業所」の定義**（実態を要するか／登記の有無で判断するか）は？
- [ ] 5. 過去登記が支障になる場合、**事前に登記を抹消・整理すれば**「初めての開設」と認められる余地はあるか？

### B. 企業区分・要件
- [ ] 6. 当社は ICT／外資系／スタートアップ／グロース のどの区分が適切か？
- [ ] 7. 当社の事業分野・設立年数・資本金・売上等で対象企業の定義を満たすか？
- [ ] 8. 床面積要件・常時雇用者数は**事業所開設時点**で満たせばよいか？（途中増員予定でも可か）
- [ ] 9. 「常駐する常時雇用者」に代表者本人を含められるか？兼務・テレワークの扱いは？

### C. スケジュール・手続き
- [ ] 10. 事前相談 → 補助事業認定申請 → 賃貸借契約 の順番で問題ないか？
- [ ] 11. 認定申請は**契約日の前日まで**。契約予定日（◯月◯日）から逆算した申請締切はいつか？
- [ ] 12. 契約は「認定申請年度の3月31日まで」「申請から1年以内に開設」。当社スケジュールで問題ないか？
- [ ] 13. 交付申請期間（翌年度4/1〜4/30）／12月最終開庁日以降申請の翌々年度扱い、当社はどちらか？

### D. 提出書類・その他
- [ ] 14. 申請時に必要な書類一式（特に**登記事項証明書／履歴事項全部証明書**の要否）は？
- [ ] 15. 履歴に過去の市内所在地が載る場合、**補足説明書や上申書**を添付できるか？
- [ ] 16. 補助金額（賃借料12ヶ月分の50%・最大1,000万円＋本店移転加算100万円）、当社賃料での見込み額は？
- [ ] 17. 「開設から3年以内に休廃止すると返還」の起算日・条件は？

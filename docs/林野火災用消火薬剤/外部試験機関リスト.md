# 外部試験機関リスト（林野火災用消火薬剤）

> [!info] このノートについて
> [[延焼抑制剤（長期難燃剤）の規格]] の各試験項目を受託してくれる機関を分野別にまとめたもの。機関名は「その分野の受託実績がある代表例」であり、対応可否・GLP適合・費用・納期は各機関へ直接要確認。

関連ノート: [[延焼抑制剤（長期難燃剤）の規格]] / [[延焼抑制剤_社内簡易試験ガイド]]

## 分野別 早見表

| 試験分野 | 受託してくれる機関の例 |
|---|---|
| 延焼抑制（燃焼）試験 | CERI、ケミトックス、カケンテストセンター ※本ガイドライン準拠可否を要確認 |
| 成分分析 | 住化分析センター、CERI、日本食品分析センター |
| 哺乳類毒性・刺激性（GLP） | 食品薬品安全センター、薬物安全性試験センター、住化分析センター、CERI |
| 水生生物毒性 | CERI、住化分析センター、うみの（海水生物） |
| 物性（粘度・密度・pH等） | CERI、住化分析センター、日本食品分析センター |
| 金属腐食・粒界腐食 | 神戸工業試験場、JFEテクノリサーチ、日鉄テクノロジー、コベルコ科研 |
| ゴム・樹脂の劣化 | CERI ほか高分子試験機関 |
| 屋外保管・微生物 | CERI、住化分析センター、日本食品分析センター |
| 色・不透明度・褪色 | CERI、ボーケン品質評価機構、カケンテストセンター |

## 機関別メモ

### 一般財団法人 化学物質評価研究機構（CERI）
- 対応：生態毒性（藻類・ミジンコ・魚類）、生分解性、物性、燃焼・難燃、色特性 ほか幅広い
- 特徴：化審法対応のGLP試験で豊富な実績。分解度試験は国内最大級
- 参考：https://www.cerij.or.jp/service/01_safety_studies/ecotoxicity_02.html

### 一般財団法人 食品薬品安全センター（秦野研究所）
- 対応：哺乳類毒性・刺激性（経口・経皮・眼・皮膚）などGLP安全性試験
- 参考：https://www.fdsc.or.jp/test/alternative_method/skin_irritation/

### 株式会社 薬物安全性試験センター
- 対応：各種安全性試験（毒性）
- 参考：https://www.dstc.jp/services/exam-saftytest/

### 株式会社 住化分析センター（SCAS）
- 対応：成分分析、毒性、生態毒性、物性、環境影響
- 参考：https://www.scas.co.jp/services/regulatoryscience/toxicity/chemical-substances-toxicity/toxicity-studies-summary.html

### うみの株式会社
- 対応：海水生物の急性・慢性毒性（魚類・甲殻類・貝類・藻類）
- 参考：https://umi-no.jp/trial/poison.html

### 株式会社ケミトックス
- 対応：燃焼性・難燃性試験（UL94等、燃焼試験50年）、生分解性
- 参考：https://www.chemitox.co.jp/business/plastic/plastic1

### 一般財団法人 カケンテストセンター
- 対応：燃焼性試験、色差・耐光性（褪色）
- 参考：https://www.kaken.or.jp/test/search/detail/20

### 金属腐食系
- 株式会社 神戸工業試験場（KMTL）… 均一腐食・局部腐食 https://www.kmtl.co.jp/service/tests/corrosion
- JFEテクノリサーチ株式会社 … 各種環境下の腐食評価、Al合金粒界腐食 https://www.jfe-tec.co.jp/tech-consul/main08.html
- 日鉄テクノロジー株式会社 … 電気化学試験・粒界腐食 https://www.nstec.nipponsteel.com/technology/corrosion/water/water_01.html
- 株式会社 コベルコ科研 … ステンレス粒界腐食試験ほか https://www.kobelcokaken.co.jp/contract/item/environment-testing/549.html

### 一般財団法人 日本食品分析センター
- 対応：成分分析、物性、微生物検査

### 一般財団法人 ボーケン品質評価機構
- 対応：色差・耐光性（褪色）など

---

> [!warning] 注意
> - 機関名は例示。対応可否・GLP適合・費用・納期は各機関へ直接確認すること。
> - **延焼抑制試験は林野火災用の新しい試験法**のため、そのまま対応できる機関が限られる可能性がある。
> - 委託数を絞るため、先に [[延焼抑制剤_社内簡易試験ガイド]] で社内スクリーニングを行うと費用を大幅に節約できる。

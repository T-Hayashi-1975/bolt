# 延焼抑制剤（長期難燃剤）の規格 ― やさしい解説つき

> [!info] このノートについて
> 消防庁ガイドラインのうち「延焼抑制剤（表中の「延」。いわゆる長期難燃剤）」に適用される試験項目と判定基準（規格）を、専門知識のない人にも分かるように解説したもの。各項目に〔規格〕〔やさしい解説〕〔身近な例え〕〔試験を受託してくれる機関の例〕を付けている。

関連ノート: [[延焼抑制剤_社内簡易試験ガイド]] / [[外部試験機関リスト]]

---

## 0. そもそも延焼抑制剤（長期難燃剤）とは？

山火事（林野火災）で使う消火薬剤の一種。水をまくだけでは乾くと再び燃え出すが、延焼抑制剤は主にリン酸塩類（肥料にも使われる成分）を含み、水分が蒸発したあとも「燃えにくくする膜」を残して火の広がりを抑える。飛行機やヘリで火の進む先の地面・樹木にまき、"燃えない帯（防火帯）"を作る使い方にも向く。

国はこの薬剤について、①火を抑える効果、②人の健康・環境への影響、③物としての性質（物性）の3分野を試験し、基準を満たすか確認する仕組みを作った。

---

## 1. 火を抑える効果（消火・延焼抑制）

### 1-1. 延焼抑制試験

- **〔規格〕** 杉の木くずで作った「燃焼ベッド」に、薬剤の混合物（0.8L/㎡）と基準薬剤10%リン酸二アンモニウム(DAP)をそれぞれまいて乾かし点火。0.9〜2.1m区間で「燃え広がる速さ」と「燃えて減る重さの割合」を測る。→ 合否ラインはなく測定値を記録（数値で実力を示す試験）。
- **〔やさしい解説〕** まかない場合や標準品と比べてどれだけ火の回りが遅くなるかを数字で見える化するテスト。合否より性能データを示すのが目的。
- **〔身近な例え〕** 乾いた薪はすぐ燃え広がるが、薬剤をしみ込ませた薪は火がなかなか進まない。その「進みにくさ」をストップウォッチと秤で測るイメージ。
- **〔試験を受託してくれる機関の例〕** CERI／ケミトックス／カケンテストセンター（→[[外部試験機関リスト]]）。※新しい試験法のため準拠可否を要確認。

## 2. 使ってはいけない成分（成分チェック）

- **〔規格〕** 次を「含まないこと」：①化審法の第一種特定化学物質 ②フェロシアン化ナトリウム ③二クロム酸塩 ④チオ尿素 ⑤ホウ酸塩・ホウ素化合物 ⑥PCB ⑦PBDE ⑧NPE ⑨硫酸アンモニウム（延のみ対象）⑩PFAS類。
- **〔やさしい解説〕** 健康や生態系に悪影響が知られる「使ってはいけない成分リスト」。入っていないことを成分表や分析で確認。
- **〔身近な例え〕** 食品の「使用禁止添加物リスト」と同じ。原材料表示をチェックして"入っていないこと"を確かめる。
- **〔試験を受託してくれる機関の例〕** 住化分析センター／CERI／日本食品分析センター。

## 3. 人の健康・環境への影響

### 3-1. 哺乳類（人など）への毒性・刺激性

| 試験項目 | 試験方法 | 規格（判定基準） |
|---|---|---|
| 急性経口毒性（飲み込み） | OECD TG420・423・425 | 濃縮物：LD50 > 500 mg/kg／混合物：LD50 > 5000 mg/kg |
| 急性経皮毒性（皮膚吸収） | OECD TG402 | LD50 > 2000 mg/kg |
| 眼刺激性 | OECD TG405 | 軽度以下の刺激 |
| 皮膚刺激性 | OECD TG404 | 一次刺激指数 < 5.0 |

- **〔やさしい解説〕** 「LD50」は"その量で半数に致命的影響が出る量"の目安。数字が大きいほど「たくさん摂らないと害が出ない＝安全」。刺激性は弱いほど良い。
- **〔身近な例え〕** 混合物 LD50 > 5000 mg/kg は食塩（約3000）より低毒性で、ほぼ食品なみ。目への「軽度以下」は真水〜ごく薄い石けん水程度。皮膚の一次刺激指数は0〜8のうち5未満なのでハンドソープ程度以下。
- **〔試験を受託してくれる機関の例〕** 食品薬品安全センター／薬物安全性試験センター／住化分析センター／CERI。※GLP適合可否を確認。

### 3-2. 水の生き物への毒性（濃縮物で試験）

| 試験項目 | 試験方法 | 規格（延） |
|---|---|---|
| 魚類 | OECD TG203 | LC50（96時間） > 200 mg/L |
| 甲殻類（ミジンコ等） | OECD TG202 | EC50（48時間） > 200 mg/L |
| 藻類 | OECD TG201・221 | ErC50（72 または96時間） > 200 mg/L |

- **〔やさしい解説〕** 川や池に流れ込んだ場合を想定。「> 200 mg/L」は水1Lに200mg（0.02%）溶けても半数に影響が出ない＝生き物にやさしい。数字が大きいほど安全。
- **〔身近な例え〕** 200 mg/L は25mプール（約300t）に約60kg溶かした濃さ。そこまで濃くしても魚の半数は生きていられる。
- **〔試験を受託してくれる機関の例〕** CERI／住化分析センター／うみの株式会社（海水生物）。

> [!note] 生分解性試験は延焼抑制剤では**対象外**（泡・ゲルのみ）。

## 4. 物としての性質（物性）

### 4-1. 基本の物性

| 試験項目 | 規格（延） |
|---|---|
| 塩類含有量 | 判定なし（測定値記録）※リン酸・アンモニウム量を測る |
| 粘度 | 判定なし（測定値記録） |
| 定常状態粘度 | 空中散布用：150〜1,500 mPa･s／その他：判定なし |
| 密度 | 空中散布用混合物：1.1 g/㎤以下／その他：判定なし |
| pH | pH 4〜10 |

- **〔やさしい解説〕** 「判定なし」は合否ラインがなく数値を記録するだけ。粘度＝とろみ、密度＝重さ、pH＝酸性・アルカリ性の強さ。空中散布用は風に流されず付着し、機体から放出できる"ちょうど良さ"が要る。
- **〔身近な例え〕** 粘度(mPa･s)：水≒1、サラダ油≒50〜80、はちみつ≒2,000〜10,000。「150〜1,500」はとろみドレッシング〜ゆるいはちみつ。密度：水=1.0、海水≒1.03、「1.1以下」は水よりほんの少し重い。pH：酢≒3、中性7、石けん水≒10、「4〜10」は食酢より弱い酸〜石けん水。
- **〔試験を受託してくれる機関の例〕** CERI／住化分析センター／日本食品分析センター。

### 4-2. 貯蔵タンクなど部材への影響（腐食・材料劣化）

| 試験項目 | 規格 |
|---|---|
| 均一腐食 | 腐食速度が金属ごとの規定値（下表）以下 |
| 粒界腐食 | Al・Mg製タンク：Al・Mgで粒界腐食なし／Al製タンク：Alで粒界腐食なし |
| 非金属材料への影響 | 硬度低下10%未満・硬度増加20%未満・体積増加0.5 mL未満 |
| 摩耗 | 摩耗した厚さ0.25 mm未満（Al製タンク貯蔵を想定する場合） |

**最大許容腐食速度（μm／年）**

|  | アルミ21℃ | アルミ49℃ | スチール | 黄銅 | マグネシウム |
|---|---|---|---|---|---|
| 湿式濃縮物 | 127 | 127 | 127 | 127 | 127 |
| 混合品 | 50 | 50 | 127 | 127 | 101 |

- **〔やさしい解説〕** 長期間タンクやホースに入れても金属がサビたりゴムがボロボロにならないか確認。「○○μm/年」は1年で金属表面が何μm(=0.001mm)溶けるかの上限。「粒界腐食なし」は結晶の境目だけが侵されもろくならないこと。
- **〔身近な例え〕** コピー用紙1枚≒100μm。「127μm/年」は1年でようやく紙1枚ぶんだけ金属が減る程度。摩耗0.25mm未満は髪の毛約2.5本ぶん。非金属劣化は、輪ゴムを油に長く漬けると伸び切る――そんな変化が起きないこと。
- **〔試験を受託してくれる機関の例〕** 神戸工業試験場／JFEテクノリサーチ／日鉄テクノロジー／コベルコ科研。ゴム・樹脂はCERI等。

### 4-3. 屋外で長く保管したときの安定性（長期保管を想定する場合）

| 試験項目 | 規格（延） |
|---|---|
| 濃縮物の屋外保管（52週） | 乾式：変色・固化・分離なし／湿式：粘度±40%以内・密度±1%以内・pH4〜10 |
| 屋外保管後の混合物の物性 | 定常状態粘度±15%以内・密度±1%以内・pH4〜10・腐食適合 |
| さらに14日保管（Al片入り容器） | 定常状態粘度±15%以内・密度±1%以内・pH4〜10 |
| 混合物の屋外保管（長期保管あり・鋼片入り52週） | ふるい通過・定常状態粘度 初期値±40%以内・密度±1%以内・pH4〜10・腐食適合 |
| 混合物の屋外保管（長期保管なし・Al片入り14日） | ふるい通過・定常状態粘度 初期値±15%以内・密度±1%以内・pH4〜10 |
| 微生物増殖に対する抵抗性 | 微生物の発生・著しい変色などがないこと |
| ポンプ圧送 | 68 L/min以上の流速が出せること |

- **〔やさしい解説〕** 屋外で1年置いても「とろみ・重さ・pHがほぼ変わらない」「カビ・腐敗が出ない」「ポンプで実用的な速さで送れる」ことを確認。「±1%」はほぼ不変、「±40%」もこの種の薬剤では十分安定とみなす範囲。
- **〔身近な例え〕** ジュースを屋外に1年置いても味の濃さ（密度・粘度）や酸っぱさ（pH）がほぼ変わらず濁りやカビも出ない――そんな長持ちの確認。ポンプ68L/minは2Lペットボトル約34本を1分で送る勢い。
- **〔試験を受託してくれる機関の例〕** CERI／住化分析センター／日本食品分析センター（微生物）。腐食は4-2の機関へ同時依頼可。

### 4-4. 着色する場合の性質

| 試験項目 | 規格（延） |
|---|---|
| 色特性 | 判定なし（記録。参考波長：赤色590nm超、青色450〜495nm） |
| 不透明度 | 判定なし（不透明かどうかを記録） |
| 褪色特性 | 非着色の薬剤と比べて色に違いがないこと |

- **〔やさしい解説〕** どこにまいたか見えるよう着色することがある。その色や濃さを記録し、色が抜けるタイプなら「最後は色が消えて景観を損なわない」ことを確認。
- **〔身近な例え〕** 運動場の白線のように"まいた跡が分かる"一方、色落ちタイプは雨や日光でだんだん薄くなり最後は地面の色に戻る。
- **〔試験を受託してくれる機関の例〕** CERI／ボーケン品質評価機構／カケンテストセンター（色差・耐光性）。

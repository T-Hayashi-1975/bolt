# 延焼抑制剤（長期難燃剤）社内簡易試験ガイド

> [!info] このノートについて
> 外部委託前に、社内で「明らかにダメな配合を落とし、有望なものに絞る」ための簡易スクリーニング方法・安価な装置をまとめたもの。
> 正式な合否判定・報告書は認定機関/GLPでしか成立しない。社内値はあくまで**当たり付け**。

関連ノート: [[延焼抑制剤（長期難燃剤）の規格]] / [[外部試験機関リスト]]

---

## 0. 大前提 ― これは「合否判定」ではなく「委託前スクリーニング」

- 正式な判定・報告書は**認定機関/GLPでしか成立しない**。社内値は目安。
- 社内で**やってはいけない/できない**ものがある（特に動物を使う毒性試験は社内で行わない）。
- **安全第一**：燃焼試験は屋外・不燃トレイ・消火器/水バケツ常備・保護具着用。金属Mg片は可燃性、廃液は適切処理。

### 社内でできる度（早見）

| 分野 | 社内簡易 |
|---|---|
| 延焼抑制（燃焼） | ◎ 比較スクリーニング可 |
| 物性（粘度・密度・pH・塩類） | ◎ 安価装置で可 |
| 腐食・材料劣化 | ○ 加速浸漬で傾向把握 |
| 屋外保管安定性 | ○ 時間はかかるが可 |
| 微生物・色・褪色 | ○ 目視+簡易器具で可 |
| 水生生物毒性 | △ ミジンコ/アルテミアで粗スクリーニングのみ |
| 哺乳類毒性・刺激性 | ✕ 社内不可（文献/SDS審査のみ） |
| 成分（禁止物質） | ✕ 分析困難（配合管理・SDS審査で代替） |

---

## 1. 延焼抑制（燃焼）試験 ― ◎社内向き

**簡易方法**：正式試験（杉木くずベッド 0.9〜2.1m）を**小型化**。同じ木材（杉のかんな屑/ウッドウール）を金属トレイに一定量・一定かさで敷き、①無処理 ②水 ③自社薬剤(0.8L/㎡相当) ④基準品10%リン酸二アンモニウム(DAP) を塗布→乾燥→同条件で着火。**「燃え広がる速さ(cm/秒)」と「燃えて減った重さの割合(%)」**を計測して比較。

**判定の見方**：自社薬剤がDAP（基準品）と同等以上に「燃え広がりが遅い」「質量減少が少ない」なら有望。合否ラインは無い項目なので**相対比較**で十分。

**必要装置（安価）**
- 精密秤 0.01g（2,000〜5,000円）… 燃焼前後の重さ
- スマホのストップウォッチ＋定規/メジャー … 燃焼速度
- 不燃トレイ・点火源・保護具・消火用水 … 数千円

**限界**：小型化により炎の挙動が実寸と異なる。順位付けには有効だが公式値の代用にはならない。

---

## 2. 物性（粘度・密度・pH・塩類）― ◎社内向き・費用対効果最高

> [!tip] 最優先で導入する価値あり。安価装置で正式値にかなり近い測定ができる。

| 項目 | 簡易装置 | 目安価格 | 判定の見方（延の規格） |
|---|---|---|---|
| 粘度 | フローカップ/ザーンカップ（流出秒→cP換算）。精密なら回転式B型粘度計 | ザーンカップ 2,800〜20,000円 ／B型 3〜8万円 | 空中散布用の定常状態粘度 **150〜1,500 mPa·s** に収まるか。その他は数値記録のみ |
| 密度 | ガラス比重浮ひょう または「一定体積を秤量」 | 浮ひょう 1,000〜3,000円 | 空中散布用混合物 **1.1 g/㎤以下** か |
| pH | ポケットpH計（要校正液）／簡易ならpH試験紙 | pH計 2,000〜6,000円 ／試験紙 500〜1,500円 | **pH 4〜10** に入るか |
| 塩類含有量 | 正式はリン酸・アンモニウム定量。社内は配合値＝仕込み量で把握（数値記録のみの項目） | 0円（計算） | 判定なし（記録用） |

**注意**：ザーンカップは温度で値が変わるので測定温度を一定に。pH計は使用前に標準液(pH4/7/10)で校正。

---

## 3. 腐食・材料劣化 ― ○加速浸漬で傾向把握

**簡易方法**：正式は90日浸漬。社内は**金属クーポン（アルミ・鋼・黄銅・マグネシウム板）を薬剤に浸け、恒温で加速（40〜50℃）**。浸漬前後の重量差から腐食の当たりを付ける。ゴム/樹脂片も同様に浸け、硬さ・体積変化を見る。

| 項目 | 簡易装置 | 目安価格 | 見方 |
|---|---|---|---|
| 均一腐食 | 精密天秤0.001g＋金属クーポン＋家庭用オーブン/小型恒温器 | 天秤 15,000〜40,000円／クーポン 数百〜数千円/枚／恒温器 家庭用流用〜5万円 | 重量減少が大きい金属がないか（正式規格は127μm/年等） |
| 粒界腐食 | USBデジタル顕微鏡（エッチング後に境目の侵食を観察） | 3,000〜20,000円 | 結晶の境目が選択的に侵されていないか |
| 非金属材料 | ゴム硬度計（デュロメータtype A）＋ノギス | 硬度計 3,500〜58,000円（特価4.5万前後）／ノギス 1,000〜3,000円 | 硬度低下10%未満・増加20%未満・膨潤（体積増）0.5mL未満 |

**限界**：加速条件は実腐食速度と厳密には対応しない。「どの金属が明らかに危ないか」を早期に弾く用途。Mgは可燃性・水素発生に注意。

---

## 4. 屋外保管安定性 ― ○時間はかかるが社内で可

**簡易方法**：試料を屋外や恒温器に一定期間置き、**2章の粘度計・比重計・pH計で前後比較**。金属片を同梱すれば腐食も同時確認。ふるいは試験用ふるい1枚（2,000〜5,000円）で通過性を見る。

- 判定：粘度±40%以内・密度±1%以内・pH4〜10 などに収まるか。
- **ポンプ圧送**：バケツ＋秤(or流量)＋ストップウォッチで1分あたりの送液量を実測。規格は **68 L/min以上**。
- **微生物**：14日静置してカビ・ぬめり・異臭・変色を目視（費用ほぼ0）。

**限界**：52週試験は短縮できない。恒温加速で傾向は掴めるが公式データにはならない。

---

## 5. 色・不透明度・褪色 ― ○目視+簡易器具で可

| 項目 | 簡易方法・装置 | 目安価格 |
|---|---|---|
| 色特性 | スマホ撮影＋カラーチャート（正式は分光測色計） | ほぼ0〜数千円 |
| 不透明度 | 白黒隠ぺい率試験紙に塗って直後・24時間後を目視 | 1,000〜3,000円 |
| 褪色特性 | ガラス板に塗り、日光またはUV-LEDライトに暴露→写真で色抜けを記録 | UVライト 1,000〜3,000円 |

いずれも「判定なし（記録）」または相対比較で足りるため社内向き。

---

## 6. 水生生物毒性 ― △粗スクリーニングのみ

> [!warning] 社内でできるのは"粗い当たり付け"まで。魚類は社内非推奨。

- **アルテミア（ブラインシュリンプ）孵化・致死試験**：乾燥卵（数百〜1,500円）を塩水で孵化させ、薬剤の各希釈で24〜48時間の生存を見る。世界的に使われる簡易毒性スクリーニング。
- **タマミジンコ遊泳阻害**：培養個体に薬剤希釈液を暴露し48時間の遊泳阻害を観察（OECD TG202の簡易版）。

**判定の見方**：正式規格は **EC50 > 200 mg/L**。社内では「200 mg/L付近で明らかに大量死しないか」を粗く確認する程度に留める。

**限界**：種・水質・個体差の管理が甘く、定量的なEC50は出せない。強毒配合を早期に外す用途に限定。

---

## 7. 社内で"できない"項目（正直な限界）

- **哺乳類毒性・刺激性（経口・経皮・眼・皮膚）＝✕**：動物実験でありGLP機関でのみ実施すべき。社内は原料SDS・文献・既知成分の毒性情報レビューに留める。
- **禁止成分の分析（PFAS・PCB・PBDE等）＝✕**：微量分析は高額機器が必要。社内は「そもそも使わない配合設計」＋原料メーカーの不含有証明（SDS/CoA）取得で担保。
- 生分解性試験は延焼抑制剤では**対象外**（泡・ゲルのみ）なので不要。

---

## 8. おすすめ「最小スターターキット」と概算予算

> [!success] まず物性＋燃焼＋目視系から始めるのが費用対効果最良。

| 装置 | 用途 | 概算 |
|---|---|---|
| 精密秤 0.01g | 燃焼前後・各種秤量 | 3,000円 |
| ザーンカップ | 粘度 | 5,000円 |
| ガラス比重浮ひょう | 密度 | 2,000円 |
| ポケットpH計＋校正液 | pH | 5,000円 |
| 白黒隠ぺい率試験紙＋UVライト | 不透明度・褪色 | 4,000円 |
| ガラス器具（ビーカー・メスシリンダー等） | 共通 | 5,000円 |
| **小計（第1段階）** | | **約2.4万円** |
| 精密天秤 0.001g | 腐食（重量法） | 25,000円 |
| ゴム硬度計 type A | 非金属劣化 | 44,000円 |
| USBデジタル顕微鏡 | 粒界腐食観察 | 10,000円 |
| 試験用ふるい・金属クーポン・恒温器 | 腐食・保管 | 30,000円 |
| **小計（第2段階）** | | **約11万円** |

→ 第1段階 約2.4万円で物性・燃焼比較・色系がカバー。第2段階まで揃えても十数万円で腐食・保管まで社内スクリーニング可能。

### 進め方の推奨
1. 第1段階キットを導入 → 物性(pH・密度・粘度)と燃焼比較で配合候補を数点に絞る
2. 有望候補のみ第2段階で腐食・保管を確認
3. 毒性・禁止成分・正式値は外部委託（[[外部試験機関リスト]]）へ ― 委託数を絞れて費用が大幅節約

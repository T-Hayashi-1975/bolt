# 気候変動フォーラム 2026 — プロジェクトドキュメント

国連支援財団（FSUN, Foundation for the Support of the United Nations / NY）を主催者、
株式会社ファイテックを共催・スポンサーの一社とする気候変動フォーラムの企画・実行ドキュメント一式です。

## イベント概要（現時点の前提）

| 項目 | 内容 |
|------|------|
| 名称（仮） | Global Climate Forum 2026 — Toward Net-Zero CO₂（気候変動フォーラム2026） |
| 大テーマ | 地球規模のCO₂排出削減（Reducing Global CO₂ Emissions） |
| 開催日 | 2026年9月11日（金） |
| 開催地 | ニューヨーク（国連本部またはNY市内会場 ※要決定） |
| 主催 | 国連支援財団（FSUN NY） |
| 共催・スポンサー | 株式会社ファイテック ほか |
| 位置づけ | UNGA（国連総会）会期中のサイドイベント |

## 重要な前提・制約（キックオフ前に共有すべき事実）

- **UNGA 81（第81回国連総会）**: 開会 2026年9月8日／一般討論（ハイレベルウィーク）9月22〜28日。
- **Climate Week NYC 2026**: 9月20〜27日。
- **本フォーラム予定日 9月11日は、ハイレベルウィーク／Climate Week本番の約11日前**にあたる。
  サイドイベントとしての「集客の山」とはタイミングがずれるため、日程の位置づけは要確認（詳細は[ロードマップ](./02_roadmap.md)・[キックオフレジュメ](./03_kickoff-agenda.md)参照）。
- **9月11日は米国の同時多発テロ追悼日（Patriot Day）**。NY市内では追悼行事が行われるため、トーン・警備・会場手配・広報上の配慮が必要。
- **準備期間は実質約2.5か月（本日2026/6/30起点）**。通常UN系大型イベントは6か月前から準備するため、本件はファストトラック運用が前提。

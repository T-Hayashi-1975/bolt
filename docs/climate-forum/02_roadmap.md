# 02. ロードマップ — 気候変動フォーラム2026 実現計画

主催: 国連支援財団（FSUN NY）／共催・スポンサー: 株式会社ファイテック ほか
開催: 2026年9月11日（金）@ ニューヨーク
大テーマ: 地球規模のCO₂排出削減

> **前提**: 起点 2026年6月30日 → 開催 9月11日 ＝ **残り約10週間（実質2.5か月）**。
> 通常6か月かける準備を圧縮するファストトラック計画。各フェーズは並走させる。

---

## 0. ゴールと成功の定義（KPI）

### イベントの目的（Why）
1. 地球規模のCO₂排出削減に向けた、国連の場での**マルチステークホルダー対話**の創出。
2. 具体的な**コミットメント／共同声明／パートナーシップ**の発表（持ち帰れる成果）。
3. 主催FSUNの招集力強化と、共催ファイテックの**国際的プレゼンス・ソリューション露出**。

### KPI（たたき台 — キックオフで合意）
| 区分 | 指標 | 目標値（案） |
|------|------|-------------|
| 規模 | 参加者数（対面） | 100〜200名／円卓は30〜50名 |
| 質 | ハイレベル登壇者数（国連高官・大使・経営層） | 8〜12名 |
| 成果 | 発表される共同声明／コミットメント | 1件以上 |
| 発信 | ライブ配信視聴・メディア露出 | 配信1,000視聴／媒体掲載5件 |
| 協賛 | スポンサー獲得（ファイテック含む） | 目標額・社数をキックオフで設定 |
| 満足 | 参加者・登壇者の満足度 | 事後アンケート 4.0/5.0 以上 |

## 2. ワークストリーム別タスク（WBS）

### WS-A: 戦略・コンセプト（オーナー: FSUN×ファイテック共同）
- [ ] 大テーマ「CO₂削減」のスコープ確定（産業脱炭素／緩和／ファイナンス等の切り口）

- [ ] 成果物（共同声明／コミットメント）の有無・形式決定

### WS-B: 国連リレーション・公式手続き（オーナー: FSUN）

## 4. 体制（RACI のたたき台）

| 役割 | 担当（案） | 主な責任 |
|------|-----------|----------|
| エグゼクティブ・スポンサー | FSUN代表／ファイテック経営層 | 最終意思決定、対外的顔 |
| プロジェクトマネージャー（PM） | ファイテック（兼FSUN連絡窓口） | 全体進行・課題管理・週次定例 |
| 国連リレーション責任者 | FSUN | 代表部スポンサー・公式手続き・会場 |
| コンテンツ責任者 | 共同 | アジェンダ・登壇者・成果物 |
| ロジ／現地責任者 | FSUN（NY現地） | 会場・AV・警備・ケータリング |
| 広報責任者 | ファイテック | ブランディング・プレス・配信 |
| 予算／契約責任者 | ファイテック | 予算・スポンサー・契約・支払 |

> R=実行, A=説明責任, C=相談, I=報告。キックオフで各タスクのA/Rを個人名まで割り当てる。

## 5. 予算フレーム（科目 — 金額はキックオフで設定）

| 科目 | 内容 | 概算レンジ感（要見積） |
|------|------|----------------------|
| 会場費 | 国連敷地内 or 市内会場、付帯設備 | 大 |
| AV・配信・通訳 | ハイブリッド配信、同時通訳 | 中〜大 |
| ケータリング・レセプション | 飲食、装花 | 中 |
| 登壇者関連 | 渡航・宿泊・謝礼（国連系は謝礼なしも多い） | 中 |
| 広報・制作 | サイト、印刷、撮影、PR | 中 |
| 警備・運営スタッフ | 9/11対応含む警備、当日要員 | 中 |
| 予備費 | 総額の10〜15% | — |

- **資金源**: 主催FSUN拠出＋スポンサー協賛（ファイテック含む）＋（任意）参加費。
- **ファイテックの拠出**: 金額・対価（冠セッション、ロゴ露出、登壇枠等）をスポンサーパッケージとして明文化。

## 6. リスク登録簿（主要リスクと対策）

| # | リスク | 影響 | 対策 |
|---|--------|------|------|
| R1 | **準備期間が短い（2.5か月）** | 品質・集客低下 | フェーズ並走、外部イベント代行の活用、スコープを成果志向に絞る |
| R2 | **9/11がハイレベルウィーク前**でVIP在NY密度が低い | 登壇者・集客 | 日程の位置づけを戦略決定（§WS-A）。リモート登壇併用、本番週フォロー設計 |
| R3 | **9/11追悼日**に伴う警備・トーンの配慮不足 | 評判・運営 | 追悼への敬意を示す演出、警備強化、市内行事との競合回避 |
| R4 | 敷地内会場・常駐代表部スポンサーが間に合わない | 開催形態 | 早期に敷地外の代替会場を並行確保 |
| R5 | ハイレベル登壇者が確保できない | 訴求力 | 早期打診、FSUNネットワーク総動員、複数候補をパイプライン管理 |
| R6 | 主催FSUNと共催ファイテックの**役割・ブランド扱いの齟齬** | 進行停滞 | キックオフで覚書・RACI・ブランドガイドを合意 |
| R7 | 予算超過 | 財務 | 予備費確保、スポンサー獲得の前倒し、ベンダー相見積 |
| R8 | 集客不足 | 規模KPI未達 | 招待制中心＋早期招待状、提携団体経由の動員 |

## 7. 直近アクション（キックオフ直後72時間）

1. PM・各WSオーナーを個人名で確定。
2. **日程9/11の位置づけ**と**会場方針（敷地内/外）**を意思決定（クリティカルパスの起点）。
3. FSUN国連リレーション窓口から、サイドイベント登録締切・代表部スポンサーの可否を照会。
4. 会場候補3件をリストアップし、空き・見積を即日依頼。
5. 登壇者ロングリスト（FSUN既存ネットワーク中心）を作成、打診優先順位を決定。
6. 課題管理表・共有ドライブ・週次定例（曜日時刻）をセットアップ。

→ キックオフで何を決めるかは [03_kickoff-agenda.md](./03_kickoff-agenda.md) を参照。
